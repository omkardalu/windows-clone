# Windows 11 Desktop Clone

A web-based recreation of the Windows 11 desktop environment, built with HTML, CSS, and JavaScript. This project demonstrates modern web development practices including flexbox layouts, responsive design, and interactive UI components.

## Features

### 🔒 Lock Screen
- Animated Windows logo splash screen
- Password input form
- System status indicators (WiFi, Battery)
- Clean, minimalist design matching Windows 11 aesthetics

### 🏠 Desktop Environment
- Windows 11-style desktop with app shortcuts
- Icons for various applications:
  - **This PC** - File explorer shortcut
  - **My Clones** - Gallery of cloned projects
  - **Integrated Search** - Web search functionality
- Taskbar with system controls

### 📁 File Explorer Clone
- Custom Windows Explorer interface
- Navigation tabs and breadcrumb path display
- Control buttons (minimize, maximize, close)
- File/folder browsing simulation
- Tool bar with navigation arrows

### 🔍 Integrated Search
- Search functionality with integrated web browsing capabilities
- Quick access to frequently visited sites

## Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Flexbox layouts, animations, and responsive design
- **SVG Icons** - Scalable graphics for UI elements

## Key Learning Outcomes

This project was created as a learning exercise for:
- ✅ Mastering Flexbox layouts and CSS Grid concepts
- ✅ Building responsive web interfaces
- ✅ Creating smooth animations and transitions
- ✅ Structuring multi-page web applications
- ✅ Implementing desktop-like UI patterns on the web

## Getting Started

1. Clone or download this repository
2. Open `index.html` in a web browser
3. Enter any password to proceed to the desktop (form is non-functional)
4. Explore the different screens and interactive elements

## Browser Compatibility

Works best on modern browsers that support:
- Flexbox
- CSS Grid
- SVG rendering
